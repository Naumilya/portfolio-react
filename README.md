# Portfolio Ильи Наумова

Личное портфолио Frontend-разработчика Ильи Наумова.

## Описание

Интерактивное портфолио с 3D-элементами, включающее секции hero, trust, about, experience, projects, telegram, setup и contacts.

## Основные особенности

- Интерактивная 3D-утка с использованием Three.js и React Three Fiber

## Стек

- React
- TypeScript
- Vite
- Three.js
- React Three Fiber
- Drei
- HLS.js

## Локальный запуск

1. Установите зависимости: `npm install`
2. Запустите dev сервер: `npm run dev`

## Доступные npm-команды

- `dev` — запуск dev сервера
- `lint` — запуск линтера
- `build` — сборка проекта
- `preview` — предпросмотр сборки
